UAGAIN SHADOW PARROT THEME
==========================

Thank you for using the UAgain Shadow Parrot Theme.

This theme pack contains custom artwork, wallpapers, Plymouth themes,
GRUB images, Plasma splash screens, login-screen backgrounds, and
application menu branding.

IMPORTANT:
Some of the files in this pack need to be copied into system folders
that are protected by Linux. You may need administrator/root permission
to copy, replace, or remove files in those locations.

If Linux will not let you paste, delete, or replace a file, right-click
inside the folder and choose:

Open as Administrator

Enter your password when prompted.

Once the administrator file window opens, you should be able to copy,
paste, replace, and remove files in that protected location.

IMPORTANT:
Always keep a backup of the original file before replacing it.

==================================================
1. DESKTOP BACKGROUNDS
==================================================

The included desktop backgrounds can be copied into:

/usr/share/backgrounds/

Open:

Root
└── usr
└── share
└── backgrounds

Copy the UAgain Shadow background images into that folder.

After copying them, you can select them from your desktop wallpaper
settings.

==================================================
2. PLASMA SPLASH SCREENS
==================================================

This folder contains a custom KDE Plasma 6 splash screen.

A Plasma splash screen is the graphical screen displayed while the
Plasma desktop is starting after login.

USER LOCATION:

The UAgain Shadow splash screen should be installed in your user's
local Plasma Look-and-Feel directory:

```
/home/(USERNAME)/.local/share/plasma/look-and-feel/
```

Replace `(USERNAME)` with your actual Linux username.

For example:

```
/home/john/.local/share/plasma/look-and-feel/
```

INSTALLATION:

1. Open your **Home** folder.

2. If you do not see the `.local` folder, press:

Ctrl + H

This will show hidden files and folders.

The `.local` folder is hidden because its name begins with a dot.

3. Open:

.local
→ share
→ plasma
→ look-and-feel

The full path is:

/home/(USERNAME)/.local/share/plasma/look-and-feel/

4. If the `look-and-feel` folder does not already exist, create the
necessary folders:

.local/share/plasma/look-and-feel/

5. Open the included UAgain Shadow splash-screen folder.

6. Locate the actual Plasma Look-and-Feel theme folder.

7. Copy the actual theme folder into:

/home/(USERNAME)/.local/share/plasma/look-and-feel/

IMPORTANT:

Do NOT copy the entire outer "Plymouth Themes" or UAgain Shadow
collection folder into the `look-and-feel` directory.

You want the actual Plasma theme folder to be directly inside:

```
/home/(USERNAME)/.local/share/plasma/look-and-feel/
```

For example:

```
/home/(USERNAME)/.local/share/plasma/look-and-feel/theme-name/
```

Plasma 6 Look-and-Feel packages contain their splash screen inside:

```
contents/splash/
```

The complete structure should look similar to:

```
/home/(USERNAME)/.local/share/plasma/look-and-feel/
└── theme-name/
└── contents/
└── splash/
```

After installation:

1. Open **System Settings**.

2. Go to:

Colors & Themes
→ Splash Screen

3. Select the **UAgain Shadow** splash screen.

4. Apply the change.

IMPORTANT:

This is a **user-local installation**. You do NOT need to copy the
theme into:

```
/usr/share/plasma/look-and-feel/
```

You also do NOT need administrator/root permissions.

If you no longer need to see hidden folders, press:

```
Ctrl + H
```

again to hide them.

Do not delete other Plasma Look-and-Feel themes.

Plasma 6 uses the Look-and-Feel package structure, including the:

```
contents/splash/
```

directory.


==================================================
3. PLYMOUTH BOOT THEMES
==================================================

Plymouth is the graphical boot screen that appears while Linux starts.

Plymouth themes are located at:

/usr/share/plymouth/themes/

Open:

Root
└── usr
└── share
└── plymouth
└── themes

The included Plymouth folder contains another folder named:

UAgain Shadow Parrot Pack

Open that folder first.

Inside it, locate the actual Plymouth theme folder.

Copy that actual theme folder into:

/usr/share/plymouth/themes/

Do NOT copy the outer "Plymouth Themes" folder itself.

The individual Plymouth theme folder needs to be placed directly inside:

/usr/share/plymouth/themes/

After installing the files, the Plymouth theme may need to be selected
and the initramfs may need to be updated depending on the Linux
distribution.

==================================================
4. GRUB
==================================================

The GRUB artwork included with this pack is located in the GRUB folder.

On the Parrot installation, the included files are intended for the
Parrot/desktop-base GRUB theme structure.

The GRUB artwork includes:

grub-16x9
grub-4x3

Both images were intentionally made the same so the boot screen remains
visually consistent.

Do not rename the files unless you know the GRUB theme configuration
has also been changed to match.

The exact location can vary depending on the Parrot OS version and
GRUB theme package installed on the computer.

Always make a backup of the original GRUB files before replacing them.

==================================================
5. LOGIN SCREEN
==================================================

The login-screen background is handled separately from the Plasma
splash screen.

The included login image is named:

login.jpg

The image should be the correct size and format for this setup:

3840 × 2160
JPEG

Go to:

/usr/share/backgrounds/

Before replacing the existing login.jpg:

1. Copy the original login.jpg.
2. Save the backup somewhere safe.
3. Choose one of the included UAgain Shadow login backgrounds.
4. Make sure it is a 3840 × 2160 JPEG.
5. Rename the replacement image:

login.jpg

6. Replace the existing login.jpg.

The filename needs to remain:

login.jpg

If the system configuration specifically references that filename,
renaming the image to something else may prevent it from being used.

==================================================
6. APPLICATION MENU LOGO / ICON
==================================================

The application menu icon can be changed directly through Plasma.

Right-click the Application Launcher button on the panel.

Choose:

Configure Application Launcher

The KDE Plasma Application Launcher configuration provides the launcher
icon settings.

Select the UAgain Shadow logo image when choosing the launcher icon.

This is generally easier and safer than manually replacing system icon
files.

==================================================
7. BACK UP YOUR ORIGINAL FILES
==================================================

Before changing anything inside:

/usr/share/

make a backup of the original files.

System folders are protected for a reason. Accidentally deleting or
replacing the wrong file can affect the desktop or boot process.

If something does not work, restore the original file from your backup.
